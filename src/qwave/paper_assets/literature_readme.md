# Literature matrix and evidence scope

`literature_matrix_template.csv` is the reusable blank template with the nine
requested columns. `literature_matrix.csv` contains five initial screened rows.
`literature_sources.json` supplies citation keys, identities, primary URLs,
verification date and scope. The linked BibTeX file is in
`../manuscript/verified_references.bib` in an exported package (or alongside these
assets in the source repository).

Metadata and abstract-level claims were checked on 2026-11-20 using publisher
records and author-uploaded arXiv records. This is **not a completed full-text or
systematic review**. A verified DOI does not verify every possible scientific
claim about that article. Full-text control bounds, spatial-disorder details,
resource comparisons and proposal-specific gaps remain explicitly unresolved.
No quotations or publisher figures are reproduced, and no credentials are needed.

The review already establishes overlap with disorder-aware transport and
derivative-based quantum robustness. It does not establish novelty for Phaseward.
Differences between a spin chain, a controlled qubit and stationary scattering
are model distinctions, not proof of an unaddressed research question.

Before a final paper, record the section/equation supporting each full-text entry,
verify any numerical result in context, expand the search with documented
inclusion/exclusion criteria, and review forward/backward citations. Add
unverified candidates only to the template; do not create a bibliographic key
until its identity has been verified on an authoritative primary record.
